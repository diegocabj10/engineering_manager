# Engineering Manager Learning Hub

This repository is designed to support the professional growth plans of Avenga engineers by giving them a clear, organized, and approachable space to develop across different learning paths.

Here we will gather materials, guides, and coaching sessions focused on AWS exam preparation and other professional development initiatives. The goal is to make this a reference point for the engineers we are supporting through this repository.

## Purpose

The main objective is to centralize learning content that helps each engineer move forward with a clear development plan, especially around cloud certifications and technical skills that support long-term career growth.

## What You Will Find Here

- Coaching and support materials for AWS certifications.
- Folder-based structure organized by learning path.
- Practical resources to study, review, and prepare for exams.
- New sections as we add more certifications or topics over time.

## Repository Structure

We already have a folder dedicated to AWS Solutions Architect Associate:

- AWS CERTIFIED SOLUTIONS ARCHITECT ASSOCIATE/

Inside this path, we will keep adding more content organized by topic, service, or study module. As the repository grows, we will also add new folders for other certifications and coaching initiatives.

What you will find inside each folder will be the modules organized according to the Pluralsight path, so the learning flow stays aligned with the certification journey.

## Primary Resources for the Associate Path

For the AWS Solutions Architect learning path, we will use these resources as a guide:

- [Pluralsight AWS Certified Solutions Architect Professional SAP-C02 path](https://app.pluralsight.com/paths/certificate/aws-certified-solutions-architect-professional-sap-c02)
- [AWS Skill Builder - Solutions Architect](https://skillbuilder.aws/category/role/solutions-architect)

These references will help us structure the coaching sessions, study materials, and practical preparation content for the team.

## How to Use This Repository

1. Open the folder that matches your current learning path.
2. Follow the guides and coaching sessions shared in each section.
3. Use this space to support your exam preparation and track your progress.
4. Share feedback to help improve the materials and make them more useful for the team.

## Who This Is For

This repository is intended for the engineers we are guiding through their development plans. The content should be useful, easy to follow, and aligned with each person's professional goals.

## How This Will Grow

This project will continue evolving over time. The goal is to add more coaching, more exams, more resources, and more learning paths based on the team's needs.

If you are visiting this repository for the first time, start with the folder that best matches your current goal and build from there.
